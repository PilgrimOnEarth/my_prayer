# my_prayer

아침기도와 저녁기도를 나누어 바치는 개인 기도 앱입니다. 설치하면 오프라인에서도 열립니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체(화면, 기도문, 동작) |
| `manifest.webmanifest` | 홈 화면 설치 정보 |
| `sw.js` | 오프라인 저장 |
| `icons/` | 앱 아이콘 |

## 배포 (Cloudflare Pages)

Workers & Pages → 만들기 → Pages → Git에 연결 → 이 저장소 선택.
프레임워크 None, 빌드 명령 비움, 출력 디렉터리 `/`.

## 폰에 설치

배포된 주소를 열고 홈 화면에 추가합니다.
- iPhone(Safari): 공유 → 홈 화면에 추가
- Android(Chrome): 메뉴 → 앱 설치

주소 끝에 `#am` 또는 `#pm`을 붙이면 아침기도 또는 저녁기도 화면으로 바로 열립니다.

## 기도문 고치는 방법

기도문은 `prayers.txt` 한 파일에 있습니다. GitHub 웹에서 바로 고칠 수 있습니다.

1. 저장소에서 `prayers.txt`를 엽니다.
2. 오른쪽 위 연필 아이콘(Edit this file)을 누릅니다.
3. 글을 고칩니다.
4. 오른쪽 위 **Commit changes…** → **Commit changes**를 누릅니다. (main에 바로 저장)
5. 1~2분 뒤 인터넷에 연결된 상태에서 앱을 닫았다 다시 열면 바뀝니다.

### 파일 형식

```
## 기도 이름
부제: 있을 때만 적습니다
시간: 아침        (아침 / 저녁 / 둘 다 중 하나)

본문 첫 문단
같은 문단의 다음 줄

빈 줄 하나가 문단을 나눕니다.

[English]
영어 본문이 있을 때만 적습니다
```

- 기도 하나는 `## 기도 이름` 줄에서 시작합니다. 앱에서는 파일 순서대로 보입니다.
- `시간:` 줄을 지우거나 잘못 적으면 아침과 저녁 모두에 나옵니다.
- 줄바꿈은 쓴 그대로 나옵니다. 문단은 빈 줄로 나눕니다.
- `○ ● ◎` 기호는 그대로 쓰면 됩니다. `●`로 시작하는 줄도 `○`와 같은 위치에서 시작합니다.
- 기도 이름을 바꾸면 그 기도의 ‘바쳤습니다’ 체크와 ‘구성’ 설정은 처음 상태로 돌아갑니다.

## 앱 파일을 고칠 때

`index.html`, `sw.js` 등 앱 파일을 고쳤다면 `sw.js`의 `VERSION` 숫자를 올려야 폰의 저장본이 바뀝니다. `prayers.txt`만 고칠 때는 올리지 않아도 됩니다.
